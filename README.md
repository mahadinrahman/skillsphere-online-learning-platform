##Project Name: SkillSphere – Online Learning Platform


##Project Purpose :SkillSphere is an online learning platform designed to connect learners with educational resources in a simple and interactive way.It helps users explore courses, manage learning content, and access educational materials efficiently using a modern web interface built with Next.js.

##Live URL:https://skillsphere-online-learning-platfor-topaz.vercel.app

##Key Fetures:

 **Responsive modern UI for all devices
 **Dynamic course/content listing
 **Clean and reusable component structure
 **Fast performance with Next.js App Router
 **Authentication-ready structure (if implemented)
 **API/data-driven rendering (JSON or backend integration)
 **Smooth navigation using Next.js routing
 **Modular and scalable project architecture
